# ShinKu-Assets

Official asset repository for the **ShinKu** Manga Reader application.

## Atmospheric Audio Soundscapes (`audio/atmosphere/`)

Seamless 60-second ambient audio loops dynamically streamed and cached by ShinKu's **Atmospheric Audio** immersion feature.
