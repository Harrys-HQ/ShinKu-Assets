## Technical Processing
All soundscapes are processed with:
- Normalized loudness target of **-20 dBFS RMS** with peak limiting at -0.5 dB to prevent digital clipping.
- **5-second equal-power crossfade loops** ensuring continuous seamless playback in audio players without pops, clicks, or silence breaks.
